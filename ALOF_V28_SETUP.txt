ALOF V28 FINAL SETUP

1. Replace your GitHub Pages index.html with index.html from this package.
2. Run ALOF_V28_SUPABASE_SETUP.sql once in Supabase SQL Editor.

V28 fixes:
- Cloud workout saves are queued immediately instead of waiting 350 ms.
- Cloud writes are serialized so rapid edits cannot overwrite one another out of order.
- First-time users create their cloud row immediately.
- Supabase INSERT/UPDATE RLS policies are included for workout logging.
- Coach lookup now correctly uses coach_access.email.
- Account and Back controls are inside the normal app header instead of using fixed positioning, reducing iOS/PWA top-area compositing/blur issues.
- Back is hidden on Home and returns through the actual navigation history.
- RPE 1-10 remains available for Swim AM/PM and Gym.
- Competition start/end dates remain supported.
